素材管理共 **11 个端点**，均为 **POST** 请求，**全部可用**（素材库、`asset://` 引用与 `callback_url` 回调均已恢复）。**不同账号之间的素材数据完全隔离**：同一账号下多把 API Key 共享同一份素材库，跨账号互不可见。

<Note>
  Base URL：`https://gogogotoken.com`。路径前缀：`/v1/seedance/asset/`。字段名注意大小写：`GroupId`、`Id`、`PageNumber`。
</Note>

## 接口列表

**素材库体系**（素材组 + `asset://` 引用）

典型流程：`CreateAssetGroup` 建组 → `CreateAsset` 登记素材 → `ListAssets` / `GetAsset` 确认 → 生成时用 `asset://<id>` 引用。

| 接口 | 端点 | 说明 |
| --- | --- | --- |
| CreateAssetGroup | `POST /v1/seedance/asset/CreateAssetGroup` | 创建素材组（免费） |
| CreateAsset | `POST /v1/seedance/asset/CreateAsset` | 登记素材（¥0.10 / 次） |
| RegisterGroup | `POST /v1/seedance/asset/RegisterGroup` | 注册已有的真人素材组（免费） |
| GetAssetGroup | `POST /v1/seedance/asset/GetAssetGroup` | 查询素材组 |
| GetAsset | `POST /v1/seedance/asset/GetAsset` | 查询单个素材 |
| ListAssetGroups | `POST /v1/seedance/asset/ListAssetGroups` | 分页列出素材组 |
| ListAssets | `POST /v1/seedance/asset/ListAssets` | 分页列出素材 |
| UpdateAssetGroup | `POST /v1/seedance/asset/UpdateAssetGroup` | 更新素材组 |
| UpdateAsset | `POST /v1/seedance/asset/UpdateAsset` | 更新素材 |

**平台上传**（不依赖素材组，返回公网 URL，可直接填进生成请求）

| 接口 | 端点 | 说明 |
| --- | --- | --- |
| CreateAssetUrl | `POST /v1/seedance/asset/CreateAssetUrl` | 上传素材换公网 URL（¥0.10 / 次） |
| ListMyUploads | `POST /v1/seedance/asset/ListMyUploads` | 查询本账号上传素材列表（免费） |

<RequestExample>

```bash 创建素材组
curl -X POST https://gogogotoken.com/v1/seedance/asset/CreateAssetGroup \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "Name": "我的素材组" }'
```

```bash 上传素材（公网 URL）

  -d '{
    "GroupId": "group_xxx",
    "Name": "参考图1",
    "AssetType": "Image",
    "URL": "https://assets.example.com/photo.jpg"
  }'
```

```bash 分页列出素材

  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \

    "Filter": {
      "GroupIds": ["group_xxx"],

    "PageNumber": 1,

  }'
```

## CreateAssetGroup

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/CreateAssetGroup \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "Name": "我的素材组" }'
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Name` | string | 否 | 素材组名称，**不超过 32 字符**；不填由平台自动生成 |
| `GroupType` | string | 否 | `AIGC`（默认）或 `LivenessFace`（真人素材组）；**不填按 `AIGC` 创建** |
| `Description` | string | 否 | 描述 |

普通素材库无需传 `GroupType`；只有要建**真人素材组**时才需要传 `"GroupType": "LivenessFace"`，之后用 `RegisterGroup` 注册到上游。

## CreateAsset

登记公网素材到指定素材组，成功扣费 **¥0.10 / 次**。创建素材组 `CreateAssetGroup` 免费。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `GroupId` | string | **是** | 所属素材组 ID，必须是本账号名下的组（由 `CreateAssetGroup` 返回） |
| `Name` | string | 否 | 素材名称，**不超过 32 字符**；不填由平台自动生成 |
| `AssetType` | string | 是 | `Image`、`Video` 或 `Audio` |
| `URL` | string | **是** | 公网 HTTPS 图片/视频/音频地址 |

<Note>
  **`GroupId` 与 `URL` 都是必填**：缺 `GroupId` 返回 `400 MissingParameter.GroupId`，缺 `URL` 返回 `400 MissingParameter.URL`。**不支持内联 base64**——只有本地文件时先用 [CreateAssetUrl](#create-asset-url) 换成公网 URL，再走 `URL` 提交。
</Note>

<Warning>
  图片尺寸有下限：宽度须在 **300–6000 px** 之间，过小（例如 1×1 占位图）会返回 `400 InvalidParameter.WidthTooSmall`。
</Warning>

成功响应只返回素材 ID（字段名是大写 `Id`），其余字段请用 `GetAsset` 查询：

```json
{ "Id": "asset-20261106123456-a1b2c" }
```

`Name` 超长返回 `400 InvalidParameter.Name`：上游实际只接受约 56 字符（报错文案写的是 64，以实际行为为准），平台还会为本账号加用户前缀，所以按上表的 32 字符以内使用。

成功后异步转存：刚创建时 `GetAsset` 的 `Status` 为 `Processing`、`URL` 为空；**要等 `Status` 变成 `Active` 之后**再在生成请求里引用 `asset://<Id>`，否则会返回 `400 InvalidParameter: The asset is still processing and is not available yet`。

## GetAsset

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/GetAsset \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "Id": "asset-20261106123456-a1b2c" }'
```

## ListAssets

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Filter.GroupIds` | string[] | 否 | 素材组 ID 列表；不填返回本账号名下全部组，不属于本账号的组会被剔除 |
| `Filter.GroupType` | string | 否 | 素材组类型，常用 `AIGC`；不填不限类型 |
| `PageNumber` | number | 否 | 页码，从 1 开始 |
| `PageSize` | number | 否 | 每页数量，默认 20 |

本账号还没有创建过素材组时返回空列表（`TotalCount: 0`、`Items: []`），不会报错。

## ListAssetGroups

分页列出本账号名下的素材组。只返回自己的组，不属于本账号的 `GroupIds` 会被剔除。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Filter.GroupType` | string | 否 | `AIGC` 或 `LivenessFace`；**不填时由平台补成 `AIGC` 再转发**，要查真人素材组请显式传 `LivenessFace` |
| `Filter.GroupIds` | string[] | 否 | 只列指定组；不填列本账号名下全部组 |
| `PageNumber` | number | 否 | 页码，从 1 开始 |
| `PageSize` | number | 否 | 每页数量，默认 20 |

## 素材上传（CreateAssetUrl） {#create-asset-url}

上传本地素材文件，平台转存后返回**公网可直接访问的 URL**，用于视频生成的 `images[]` / `metadata.content[]` 等字段。成功一次扣费 **¥0.10**。

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/CreateAssetUrl \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@/path/to/photo.jpg"
```

成功响应：

```json
{
  "id": "upl_ddbdb9cdb5f109c5",
  "url": "https://gotoken-oss-com.oss-cn-shanghai.aliyuncs.com/uploads/1/ddbd....jpg",
  "size": 44891,
  "content_type": "image/jpeg",
  "expires_in_days": 30
}
```

| 项 | 说明 |
| --- | --- |
| 请求格式 | `multipart/form-data`，文件字段名 `file` |
| 支持类型 | 图片 jpg / png / webp / gif；视频 mp4 / mov；音频 mp3 / wav（按文件真实内容识别，改名无效） |
| 大小上限 | 图片 20MB / 视频 200MB / 音频 50MB |
| 频率限制 | 每个账号 1000 次 / 天（同一账号下多把 API Key 共用此额度） |
| 有效期 | URL **30 天**后自动失效，请及时用于生成任务 |
| 重复上传 | 相同内容自动去重，秒回同一 URL（照常计费）。去重按账号隔离：别人传过同一文件不影响你的 URL 和有效期。重复上传时若剩余有效期不足 1 天，会自动刷新回完整 30 天 |

控制台 **素材管理** 中的素材组、`asset://` 链接属于素材库体系，CreateAssetUrl 上传的素材**不会**进入素材库，也不生成 `asset://`——返回的公网 URL 直接使用即可。

## 我的上传列表（ListMyUploads） {#list-my-uploads}

查询本账号通过 CreateAssetUrl 上传过的素材列表，按最近上传时间倒序。**只读、免费**。

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/ListMyUploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "PageNumber": 1, "PageSize": 20 }'
```

成功响应：

```json
{
  "total": 2,
  "page_number": 1,
  "page_size": 20,
  "items": [
    {
      "id": "upl_ddbdb9cdb5f109c5",
      "url": "https://gotoken-oss-com.oss-cn-shanghai.aliyuncs.com/uploads/1/ddbd....jpg",
      "size": 44891,
      "content_type": "image/jpeg",
      "uploaded_at": 1792947042,
      "expires_in_days": 25
    }
  ]
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `PageNumber` | number | 否 | 页码，从 1 开始 |
| `PageSize` | number | 否 | 每页数量，默认 20，最大 100 |

`expires_in_days` 为剩余有效天数（0 表示已过期，重新上传同一文件会自动刷新回 30 天）。

## 在图生视频中引用

素材库里的素材用 `asset://<素材 Id>` 引用：

```json
{
  "type": "image_url",
  "image_url": { "url": "asset://asset-20260627000800-l6jq6" },
  "role": "first_frame"
}
```

平台上传（CreateAssetUrl）得到的公网 URL 直接填：

```json
{
  "type": "image_url",
  "image_url": { "url": "https://gotoken-oss-com.oss-cn-shanghai.aliyuncs.com/uploads/1/ddbd....jpg" },
  "role": "first_frame"
}
```

两者都放进 [视频生成](/video-generations) 的 `images[]` 或 `metadata.content`。

## 常见问题

**上传报 `MissingParameter.GroupId` / `MissingParameter.URL`？**

`CreateAsset` 两个字段都必填：`GroupId` 用 `CreateAssetGroup` 返回的 ID，`URL` 必须公网可访问。没有公网地址时先用 [CreateAssetUrl](#create-asset-url) 换成 URL。

**传 base64（`Data`）报 `MissingParameter.URL`？**

上游不支持内联 base64，只接受公网 `URL`。请改走 [CreateAssetUrl](#create-asset-url) → `CreateAsset` 两步。

**上传报 `DownloadFailed`？**

上游拉不到这个地址：防盗链、需登录、内网地址或临时链接已过期。换一条公网直链，或先用 [CreateAssetUrl](#create-asset-url) 转存。

**上传报 `WidthTooSmall`？**

图片宽度必须在 300–6000 px 之间，换一张尺寸正常的图。

**asset:// 图生报 `The asset is still processing`？**

素材还在转存，用 `GetAsset` 查到 `Status` 变为 `Active` 后再提交。

**asset:// 图生报找不到素材？**

确认 asset 由当前**账号**创建（同账号下换 API Key 不影响）、素材组未解绑，且素材 `Status` 已是 `Active`。可先改用公网图片链接验证流程。

**字段名写错？**

使用 `GroupId`、`Id`、`PageNumber`，不是 `group_id`、`GroupID`、`Page`。
