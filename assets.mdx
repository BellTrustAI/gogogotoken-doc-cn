素材管理共 **11 个端点**，均为 **POST** 请求，**全部可用**（素材库、`asset://` 引用与 `callback_url` 回调均已恢复）。**不同账号之间的素材数据完全隔离**：同一账号下多把 API Key 共享同一份素材库，跨账号互不可见。

<Note>
  Base URL：`https://gogogotoken.com`。路径前缀：`/v1/seedance/asset/`。字段名注意大小写：`GroupId`、`Id`、`PageNumber`。
</Note>

## 素材上传（CreateAssetUrl） {#create-asset-url}

上传本地素材文件，平台转存后返回**公网可直接访问的 URL**，用于视频生成的 `images[]` / `metadata.content[]` 等字段。成功一次扣费 **¥0.10**。

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/CreateAssetUrl \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@/path/to/photo.jpg"
```

成功响应：

```json
{
  "id": "upl_ddbdb9cdb5f109c5",
  "url": "https://gotoken-oss-com.oss-cn-shanghai.aliyuncs.com/uploads/1/ddbd....jpg",
  "size": 44891,
  "content_type": "image/jpeg",
  "expires_in_days": 30
}
```

| 项 | 说明 |
| --- | --- |
| 请求格式 | `multipart/form-data`，文件字段名 `file` |
| 支持类型 | 图片 jpg / png / webp / gif；视频 mp4 / mov；音频 mp3 / wav（按文件真实内容识别，改名无效） |
| 大小上限 | 图片 20MB / 视频 200MB / 音频 50MB |
| 频率限制 | 每个账号 1000 次 / 天（同一账号下多把 API Key 共用此额度） |
| 有效期 | URL **30 天**后自动失效，请及时用于生成任务 |
| 重复上传 | 相同内容自动去重，秒回同一 URL（照常计费）。去重按账号隔离：别人传过同一文件不影响你的 URL 和有效期。重复上传时若剩余有效期不足 1 天，会自动刷新回完整 30 天 |

控制台 **素材管理** 中的素材组、`asset://` 链接属于素材库体系，CreateAssetUrl 上传的素材**不会**进入素材库，也不生成 `asset://`——返回的公网 URL 直接使用即可。

## 我的上传列表（ListMyUploads） {#list-my-uploads}

查询本账号通过 CreateAssetUrl 上传过的素材列表，按最近上传时间倒序。**只读、免费**。

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/ListMyUploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "PageNumber": 1, "PageSize": 20 }'
```

成功响应：

```json
{
  "total": 2,
  "page_number": 1,
  "page_size": 20,
  "items": [
    {
      "id": "upl_ddbdb9cdb5f109c5",
      "url": "https://gotoken-oss-com.oss-cn-shanghai.aliyuncs.com/uploads/1/ddbd....jpg",
      "size": 44891,
      "content_type": "image/jpeg",
      "uploaded_at": 1792947042,
      "expires_in_days": 25
    }
  ]
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `PageNumber` | number | 否 | 页码，从 1 开始 |
| `PageSize` | number | 否 | 每页数量，默认 20，最大 100 |

`expires_in_days` 为剩余有效天数（0 表示已过期，重新上传同一文件会自动刷新回 30 天）。

## CreateAsset

登记公网素材到指定素材组，成功扣费 **¥0.10 / 次**。创建素材组 `CreateAssetGroup` 免费。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `GroupId` | string | 否 | 所属素材组 ID；不填则由上游放入默认组 |
| `Name` | string | 否 | 素材名称；不填由平台自动生成 |
| `AssetType` | string | 是 | `Image` 或 `Video` |
| `URL` | string | 二选一 | 公网 HTTPS 图片/视频地址（**推荐**） |
| `Data` | string | 二选一 | 图片/视频的 base64 内容（可含 `data:` 前缀）。原样转发给上游，大文件建议改用 `URL` |

<Note>
  `URL` 与 `Data` 二选一，**优先用 `URL`**：已有公网直链直接填；只有本地原图时可先用 [CreateAssetUrl](#create-asset-url) 换公网 URL，再走 `URL` 提交，比内联 base64 更稳。
</Note>

## 常见问题

**上传报 URL 无效？**

换一张能公网直接打开的 `https` 链接；只有本地原图时先用 [CreateAssetUrl](#create-asset-url) 换成公网 URL。`Data`（base64）会原样转发上游，大文件更容易超时，建议只作兜底。

**asset:// 图生报找不到素材？**

确认 asset 由当前**账号**创建（同账号下换 API Key 不影响）且素材组未解绑。可先改用公网图片链接验证流程。

**字段名写错？**

使用 `GroupId`、`Id`、`PageNumber`，不是 `group_id`、`GroupID`、`Page`。
