素材管理共 **10 个端点**，均为 **POST** 请求。不同 API Key 之间的素材数据完全隔离。

<Note>
  Base URL：`https://gogogotoken.com`。路径前缀：`/v1/seedance/asset/`。字段名注意大小写：`GroupId`、`Id`、`PageNumber`。
</Note>

<Warning>
  **渠道升级期间**：素材库体系 8 个端点（CreateAssetGroup / CreateAsset / GetAsset / GetAssetGroup / ListAssets / ListAssetGroups / UpdateAsset / UpdateAssetGroup）**全部暂不可用**，调用会返回错误。可用的是平台自带的两个素材上传接口：[素材上传 CreateAssetUrl](#create-asset-url) 与 [我的上传列表 ListMyUploads](#list-my-uploads)——上传即得公网 URL，可直接填进视频生成的 `images[]` / `metadata.content[]`。素材库恢复时间以实际调用结果为准。
</Warning>

## 素材上传（CreateAssetUrl） {#create-asset-url}

上传本地素材文件，平台转存后返回**公网可直接访问的 URL**，用于视频生成的 `images[]` / `metadata.content[]` 等字段。成功一次扣费 **¥0.10**。

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/CreateAssetUrl \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@/path/to/photo.jpg"
```

成功响应：

```json
{
  "id": "upl_ddbdb9cdb5f109c5",
  "url": "https://gotoken-oss-com.oss-cn-shanghai.aliyuncs.com/uploads/1/ddbd....jpg",
  "size": 44891,
  "content_type": "image/jpeg",
  "expires_in_days": 30
}
```

| 项 | 说明 |
| --- | --- |
| 请求格式 | `multipart/form-data`，文件字段名 `file` |
| 支持类型 | 图片 jpg / png / webp / gif；视频 mp4 / mov；音频 mp3 / wav（按文件真实内容识别，改名无效） |
| 大小上限 | 图片 20MB / 视频 200MB / 音频 50MB |
| 频率限制 | 每个账号 1000 次 / 天（同一账号下多把 API Key 共用此额度） |
| 有效期 | URL **30 天**后自动失效，请及时用于生成任务 |
| 重复上传 | 相同内容自动去重，秒回同一 URL（照常计费）。去重按账号隔离：别人传过同一文件不影响你的 URL 和有效期。重复上传时若剩余有效期不足 1 天，会自动刷新回完整 30 天 |

控制台 **素材管理** 中的素材组、`asset://` 链接属于素材库体系（当前升级期间不可用），CreateAssetUrl 上传的素材**不会**进入素材库，也不生成 `asset://`——返回的公网 URL 直接使用即可。

## 我的上传列表（ListMyUploads） {#list-my-uploads}

查询本账号通过 CreateAssetUrl 上传过的素材列表，按最近上传时间倒序。**只读、免费**。

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/ListMyUploads \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "PageNumber": 1, "PageSize": 20 }'
```

成功响应：

```json
{
  "total": 2,
  "page_number": 1,
  "page_size": 20,
  "items": [
    {
      "id": "upl_ddbdb9cdb5f109c5",
      "url": "https://gotoken-oss-com.oss-cn-shanghai.aliyuncs.com/uploads/1/ddbd....jpg",
      "size": 44891,
      "content_type": "image/jpeg",
      "uploaded_at": 1792947042,
      "expires_in_days": 25
    }
  ]
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `PageNumber` | number | 否 | 页码，从 1 开始 |
| `PageSize` | number | 否 | 每页数量，默认 20，最大 100 |

`expires_in_days` 为剩余有效天数（0 表示已过期，重新上传同一文件会自动刷新回 30 天）。

## CreateAssetGroup

```bash
curl -X POST https://gogogotoken.com/v1/seedance/asset/CreateAssetGroup \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "Name": "我的素材组" }'
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `Name` | string | 是 | 素材组名称 |
| `Description` | string | 否 | 描述 |

## CreateAsset

登记公网素材到指定素材组，成功扣费 **¥0.10 / 次**。创建素材组 `CreateAssetGroup` 免费。

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `GroupId` | string | 否 | 所属素材组 ID。部分渠道的素材组已由平台固定，可不填；填写后在这类渠道会被忽略。具体请咨询管理员 |
| `Name` | string | 是 | 素材名称 |
| `AssetType` | string | 是 | `Image` 或 `Video` |
| `URL` | string | 二选一 | 公网 HTTPS 图片/视频地址 |
| `Data` | string | 二选一 | 图片/视频的 base64 内容（可含 `data:` 前缀）。平台会自动转存后登记，无需自备图床 |

<Note>
  `URL` 与 `Data` 二选一：已有公网直链用 `URL`；只有本地原图用 `Data` 传 base64，平台自动转存为公网素材，无需你自己搭图床。
</Note>

## 在图生视频中引用

用 CreateAssetUrl 返回的公网 URL 直接填进 [视频生成](/video-generations) 的 `images[]` 或 `metadata.content`：

```json
{
  "type": "image_url",
  "image_url": { "url": "https://gotoken-oss-com.oss-cn-shanghai.aliyuncs.com/uploads/1/ddbd....jpg" },
  "role": "first_frame"
}
```

<Warning>
  **暂不支持**：`asset://` 引用当前不可用（渠道升级期间），提交会返回 400。请一律使用公网 URL。
</Warning>

## 常见问题

**上传报 URL 无效？**

换一张能公网直接打开的 `https` 链接；或改用 `Data` 字段直接传图片 base64，由平台自动转存，无需自备图床。

**asset:// 图生报找不到素材？**

确认 asset 由当前 Key 上传且素材组未解绑。可先改用公网图片链接验证流程。

**字段名写错？**

使用 `GroupId`、`Id`、`PageNumber`，不是 `group_id`、`GroupID`、`Page`。
